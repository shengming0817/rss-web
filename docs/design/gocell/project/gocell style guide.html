GoCell style guide · v1

极简、信息密度高、面向开发者后台。基于 Geist + Geist Mono + Instrument Serif， 单一蓝紫色 accent，几乎纯白/纯黑底，1px 细线与极轻阴影建立层级。

STYLE linear-minimal · admin FILES tokens.css · v1-linear.css · v1-deep.css

设计 DNA

01 · principles

六条规则用来决定任何新页面或新组件是否"长得像 GoCell"。

01
线条而非块面

用 1px --line 细线分隔结构，几乎不用大色块或描边阴影来分区。

02
单一 Accent

蓝紫 oklch(0.58 0.19 268)。只在主按钮、链接、focus ring、进度条出现。

03
Serif 标题 + Sans 正文

页面 H1 用 Instrument Serif 增加调性；其余全部 Geist。数字与 ID 用 Geist Mono。

04
紧凑信息密度

表格行 40–44px、字号 13–13.5px。按钮高 28–30px。永远优先一行装下。

05
Mono 用于元数据

ID、计数、时间戳、键盘快捷键、分组标签全部用 Mono + 小字号 + tracking。

06
阴影几乎不存在

只在 raised 元素、激活态、模态出现，且非常浅。结构靠线，不靠 elevation。

如何复用

14 · how to reuse
FILE 01
tokens.css

色彩、字体、圆角、阴影变量。永远第一个引入。
包含完整 light/dark 主题。

FILE 02
v1-linear.css

所有 .v1-* 组件：sidebar、top bar、btn、input、seg、table、cell card、flag、drawer。

FILE 03
v1-deep.css

所有 .v1d-* 浮层：command palette、modal、toast、drawer label。

DO
保留

Serif H1 + Mono 计数 / chip / kbd 的对比；1px line 为主，shadow 极少；ID 永远 mono。

DON'T
避免

多 accent 色、彩色 chip 满天飞、大圆角（>14px）、emoji、渐变背景、阴影分块。

SCALE
数字基线

btn 30px · row 44px · sidebar 232px · top 44px · pad 24–28px · 字号 13–13.5px。
